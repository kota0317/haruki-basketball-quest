# HARUKI BASKETBALL QUEST

GitHub Pages で動作する学習・バスケアプリ。Node.js でテスト: `node tests/smoke.cjs && node tests/outbox.mjs && node tests/dashboard.mjs && node tests/cloud-integration.cjs`。Supabase JS は package-lock.json にバージョン固定され、MITライセンスのUMD配布物を vendor に配置。秘密鍵は置かない。

## 親子同期

親子はそれぞれ異なるメールアドレス・パスワードで SYNC から新規登録、確認メールを承認してログインする。保護者は「保護者として利用」から15分有効・1回限りの招待コードを発行し、ハルキ本人は自分のアカウントで「ハルキとして利用」を選び招待コードを入力する。コードを第三者に渡さない。ハルキの学習端末で「この端末の記録を紐付けて同期」を押すと、初回移行前の記録を別キーに保存し、以降はID付き記録を自動送信する。

保護者は PARENT または SYNC で学習メニュー、時間と問題分野を設定でき、無効化によりメニューを削除する。ハルキ側は再表示・オンライン復帰・概ね60秒間隔で更新する。通信失敗時は端末内の送信待ち記録を保持し、復旧後に再試行する。別アカウントへ勝手に移行しない。端末内のバックアップを定期的に保存する。旧形式のIDのないバックアップを別端末へ繰り返し移行した場合、完全な重複判定はできない。

保護者はリンクされた学習者の記録を閲覧し、メニューを編集できる。実績への変更は禁止。RLSと短命の高強度ワンタイム招待で保護し、管理者用の鍵をクライアントに置かない。試作アプリの英検は24例題で、模試・リスニング・英作文・面接は未実装。バスケは8ターンの簡易シミュレーションで、5選手の個別操作や本格アニメは未実装。

## 運用の限界

実機2台を使った同期・メール配送の確認は未了。ブラウザのストレージ削除や端末故障で未送信の記録を失う可能性がある。同期中のバックアップ復元は安全のため無効にしている。ローカルストレージの上限や同じ端末の複数タブによる同時編集は避ける。招待リンクの取り消しUIとパスワード再設定UIは未実装。保護者への閲覧許可は現在プロジェクト管理者のみが取り消せる。サービスの料金・制限は Supabase 側に従う。
