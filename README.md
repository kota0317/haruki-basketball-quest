# HARUKI BASKETBALL QUEST

このブランチはGoogle Cloud・独自SMTP・普段のID/パスワード入力を使わない親子同期の開発版です。本番設定・公開は未完了のため、実際の学習記録に使用しないでください。

親が初回にSupabase管理画面で自分の端末登録要求を承認し、親が発行する一度限りの招待コードでハルキの端末を登録する設計です。登録後はSupabase Authの端末セッションを利用します。ブラウザデータ削除後、親はSupabase管理画面から、ハルキは親の承認で端末を再登録します。

学習メニューと目標、復習と学習実績の同期、旧データの明示的な移行、オフライン時の再送を用意していますが、実際の認証・権限・別端末同期は未検証です。端末停止はアプリデータへのアクセスをRLSで拒否する設計であり、Supabase Authリフレッシュトークン自体の遠隔失効や端末内データの遠隔消去は実装していません。

詳細は [親子端末登録の設計](cloud/OWNER_APPROVAL_DESIGN.md) を参照してください。秘密鍵やサービスロールキーを公開コードに置きません。試作版の英検は24例題で、模試・リスニング・英作文・面接は未実装。バスケは簡易シミュレーションです。

`npm ci` の後、`npm test` で単体・模擬テストを実行できます。PGliteによる隔離されたローカルPostgreSQLのテストは、実際のSupabase Auth・Androidの代替ではありません。
