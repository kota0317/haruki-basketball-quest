# HARUKI BASKETBALL QUEST 試作版

GitHub Pages向け静的アプリ。index.htmlを開いて利用。学習時間・回答・試合結果を端末のlocalStorageに保存し、JSONでバックアップ可能。端末間同期、認証、保護者専用アクセスはありません。ブラウザデータ削除で記録が失われるため、重要なデータを唯一の保存先にしないでください。

未実装：診断・模試、リスニング・英作文・面接。正答率は学習状況の参考であり実力推定には使えません。

公式日程：2026年度第3回従来型、個人申込2026/10/30〜12/14（支払方法により12/11締切）、一次2027/1/24、二次2/28または3/7。https://www.eiken.or.jp/eiken/schedule/2026-examinee.html

試合は8ターンの簡易シミュレーションです。5人の役割を前提にセンターの作戦を選びますが、5選手を個別操作するゲームではありません。国内で3勝するとNBAの対戦相手を解放します。

## 保存とバックアップ

学習メニュー、完了履歴、XP、試合結果と途中の試合は、利用した端末・ブラウザの保存領域に記録されます。同じスマホでも別のブラウザやシークレットモードには共有されません。親が編集する場合はハルキのスマホの同じブラウザを使用してください。クラウド同期・ログイン・家族コードは使用しません。

管理 → 学習サマリーからJSONバックアップを保存できます。復元は現在の記録を置き換えるため、先に現在の記録をバックアップしてください。ブラウザのデータ消去、端末の故障・機種変更で記録が失われる場合があります。バックアップは別の安全な場所にも保管してください。


## バスケットボール学習クエスト

単語・文章・会話・読解の進捗は、この端末の同じ保存データに追加されます。英単語は平日・土曜に英日10問と日英10問、日曜は月〜土に出題した問題から各最大25問です。問題数が足りない週は記録のある問題だけ出題します。読解はオリジナルの12題から直近10題を避けて抽選します。文章と会話は各5題、間違いは正解するまで復習します。日曜はそれぞれ月〜土に出題済みの問題から最大5題ずつ出題し、記録がない場合は出題しません。学習メニューの完了に加え、英語クエストの正解でも追加XPを獲得します。

学校の出場実績と表記は大会公式の[2025年男子出場校一覧](https://wintercup2025.japanbasketball.jp/wp-content/uploads/WC2025_team_men.pdf)と[2024年男子出場校一覧](https://wintercup2024.japanbasketball.jp/wp-content/uploads/WC2024_team_men.pdf)を確認しています。星や戦術はゲーム用の架空設定で、学校公式のユニフォームやロゴではありません。

初回は通信が必要です。静的ファイルを端末に保存できた後はオフラインでも利用を試みます。端末やブラウザのデータ消去で学習記録は失われるため、定期的にJSONバックアップを保管してください。


2026年の全中男子24校とウインターカップ男子60校は、添付の出場校一覧と[ウインターカップ2026出場校一覧](https://www.basketball-zine.com/article/detail/117968)をもとに収録。毎日5チームを抽選し、両大会から最低1チームずつ表示します。対戦能力はゲーム上の設定です。既存ユーザーも能力の基準を10に統一し、レベルによる成長分は維持します。


## HIGHLIGHTS と報酬

英語クエストの正解時は、同じ日・同じ問題で重複しない追加XPを獲得します。レベルアップや連続記録で解放された演出・称号、追加XP、試合ハイライトと設定は同じ端末の保存データとJSONバックアップに含まれます。勝敗はプレー結果から計算し、演出はその結果を表示します。

効果音は初期状態でミュートです。演出はフル・簡易・OFFから選択でき、いつでもスキップできます。
