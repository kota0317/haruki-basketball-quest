# HARUKI BASKETBALL QUEST

このブランチはパスワード入力不要の親子同期の開発版です。本番公開・設定は未完了であり、実際の学習記録に使用しないでください。公開サイトには現在の端末内保存版が残っています。

構想では、保護者が初回にGoogleで本人確認し、ハルキの端末を期限付き招待コードで承認します。ハルキにメールアドレスは不要です。以後はSupabase Authの端末セッションを利用します。Google側の判断で本人確認を求められる場合や、ブラウザデータ削除後に再登録が必要な場合があります。

保護者のメニュー編集、学習記録・復習・試合結果の同期、ローカル記録の明示的な移行と再送を用意していますが、新認証方式でのデータベース適用・実機検証は未実施です。デバイス停止はアプリのRLSアクセスを拒否する設計であり、停止対象のSupabase Authリフレッシュトークンの遠隔失効や端末内データの遠隔消去は実装していません。

[認証方式の設計と未完了事項](cloud/DEVICE_AUTH_DESIGN.md) を参照してください。秘密鍵やサービスロールキーは含めません。試作版の英検は24例題で模試・リスニング・英作文・面接は未実装、バスケは簡易シミュレーションです。

`npm ci` の後、`npm test` で単体・模擬テストを実行できます。Supabase JSのバージョンは固定され、MITライセンスのUMD配布物をvendorに配置しています。
